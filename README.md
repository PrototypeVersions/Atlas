# ATLAS — A Merchandise Exchange

A Bauhaus-style merchandise discovery marketplace prototype built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Prototype features

- Free-text merchandise search
- Browse/filter by place, interest, product, vibe, and price
- City and state discovery
- Individual merchandise mode
- Wholesale mode for cases, lots, bundles, and pallets
- Unit-cost and estimated retail-value display for wholesale inventory
- Large fictional demo catalog for testing filters
- Stylized merchandise illustrations generated in-browser
- Product detail dialog
- Demo shopping cart
- Responsive layout for desktop and mobile

All products, prices, quantities, and inventory shown in this prototype are fictional demo data.

## GitHub Pages

Publish from the `main` branch and `/ (root)` under **Settings → Pages → Build and deployment**.
